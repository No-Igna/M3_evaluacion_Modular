# Modulo 3 (Sistema de Inventario - BroadSonick)

Aplicación web básica para la gestión de productos de inventario.  
Permite agregar, editar y eliminar productos, además de calcular automáticamente el valor total del inventario.

---

## Tecnologías utilizadas

- HTML5
- JavaScript (Vanilla JS)
- Bootstrap 5

---

## Funcionalidades

- Agregar nuevos productos
- Editar productos existentes
- Eliminar productos
- Visualizar listado en tabla dinámica
- Cálculo automático del valor total del inventario
- Interfaz responsive

---

## 🛠 Cómo usar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en el navegador.
3. Utilizar el formulario para agregar productos.
4. Usar los botones **Editar** o **Eliminar** para gestionar el inventario.

---

## 📊 Lógica principal

El sistema funciona mediante:

- Un arreglo `inventario` que almacena los productos.
- Manipulación del DOM para actualizar la tabla dinámicamente.
- Cálculo automático del valor total multiplicando `precio × stock`.
